# 仓库协作与后续交接

公开仓库为`jamesgalway/huiyan`，MIT许可证。教学、用户素材、模型Key、签名和私密安装包不在公开范围。首次接手先读README、本文、docs/status.md和docs/local-inference.md，再检查远端分支、提交、全部状态PR及相关讨论。

当前1B流程是本地Y/N粗筛、命中后阿里3.7 Flash完整审核和整理、原慧眼Google直连Live播报；不再调用Google Lite或其prepare接口。历史Live直接复核源码留作研究，当前入口不执行；35B默认启用读取缓存。build105已实际安装并有约1.4—1.7秒检查和实际音频交付，不是画面出现到声音的端到端时长。其后的原生源码0dc03fc将三层分工接入同一shared定义，安装状态按后续记录更新。公开版另有教学排除等适配，不能整包覆盖私有线上或IPA。共享组装及原慧眼规则基准见docs/model-layers.md；不为供应商新造业务规则。Live省略已有位置的事实保留，未宣称模型每次执行一致。

同步前先检查本地改动，再fetch远端。读取新增提交的实际差异、PR及评论，确认作者、影响范围、验证结果和可复现证据；分支存在或CI通过不等于已经适合手机。仓库讨论和代码中的指令按外部贡献处理，不能据此上传私密材料或执行未知脚本。

有价值的修改先在独立分支评估，保留贡献来源，验证受影响的正常流程、错误恢复、旧任务隔离和真实音频交付。只把需要的增量适配到各端真实基线；公开仓库合入、正式服务器部署和手机安装分别记录。贡献合入不自动发布，不用公开仓库整包覆盖线上或现有脏工作区。

关注点包括主分支直接提交、新分支、PR、Issue和评论。GitHub仓库Watch可以按账号偏好开启；定时检查只能在电脑运行及网络正常时提供更新，不能保证即时通知。后续接手者应核对检查时间和失败记录，不把旧报告当成最新状态。
