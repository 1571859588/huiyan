# 慧眼 iOS 原生与本地实验

公开版已排除教学入口和教学机位桥。源码基于实际build102，并包含后续阿里决策音频保护的初始化修正。

构建、自己的域名和签名、生成新授权、下载模型及离线计时，请从仓库根目录的`docs/ios-build.md`与`docs/local-inference.md`开始。

不要使用运营者的站点、手机授权或签名材料。模型权重、生成的推理库、Google SDK构建结果和私有IPA均不在Git中；固定上游源和补丁位于`.github/scripts`，权重文件校验在`AccessibleVision/LocalScreening/model-catalog*.json`。
